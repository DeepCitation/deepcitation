8. Skill Documentation Summary

8a. Inline span wrapping (annotate-html.md + build-marked-html.md)

Elements with data-citation-key / data-cite MUST be inline <span> elements. Never place on block elements (<div>, <p>, <td>, <li>). Wrap the anchor text (max 4 words / 40 chars) in the span.

8b. Drawer trigger (annotate-html.md)

Place <div data-dc-drawer-trigger></div> — empty, no onclick, no button markup. The CDN runtime auto-renders CitationDrawerTrigger + CitationDrawer into it.

8c. Download URL (build-marked-html.md)

For URL sources, include downloadUrl in the verification data (the original URL from prepare). The popover shows a download icon when this is present.
